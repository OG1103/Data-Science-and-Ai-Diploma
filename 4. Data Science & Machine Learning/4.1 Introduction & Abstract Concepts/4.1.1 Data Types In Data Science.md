# Data Types in Data Science and AI

## Introduction

Understanding different types of data is crucial for selecting appropriate algorithms and preprocessing techniques in AI and Data Science projects.

---

## 1. Structured Data

**Definition**: Highly organized data in tables with rows and columns (databases, spreadsheets).

**Examples**: Customer databases, financial transactions, sales records, sensor readings

**ML Use Cases**: Regression, classification, forecasting, recommendation systems

**Tools**: Pandas, SQL, Scikit-learn, Apache Spark

---

## 2. Unstructured Data

**Definition**: Data without predefined format or organization (80-90% of all data).

**Types & Examples**:

- **Text**: Emails, social media, articles, reviews
- **Images**: Photos, medical scans, satellite imagery
- **Video**: Surveillance, movies, YouTube content
- **Audio**: Voice recordings, music, podcasts

**ML Use Cases**: NLP, sentiment analysis, computer vision, object detection, speech recognition, image classification

**Tools**: NLTK, spaCy, BERT, GPT, OpenCV, TensorFlow, PyTorch, YOLO

---

## 3. Semi-Structured Data

**Definition**: Hybrid format with tags/markers providing some organization.

**Examples**: JSON, XML, HTML, emails, log files, NoSQL documents

**ML Use Cases**: Web scraping, social media analytics, log analysis, knowledge graphs

**Tools**: BeautifulSoup, MongoDB, Elasticsearch, Neo4j

---

## 4. Time Series Data

**Definition**: Data points indexed in time order, showing changes over time.

**Examples**: Stock prices, weather data, website traffic, IoT sensors, sales figures

**ML Use Cases**: Forecasting, anomaly detection, trend analysis, predictive maintenance

**Models**: ARIMA, Prophet, LSTM, GRU, Transformers

---

## 5. Spatial/Geospatial Data

**Definition**: Data representing physical locations and geographic information.

**Examples**: GPS coordinates, satellite imagery, maps, traffic patterns, delivery routes

**ML Use Cases**: Location recommendations, route optimization, urban planning, real estate prediction

**Tools**: GeoPandas, Folium, PostGIS, Google Maps API

---

## 6. Graph Data

**Definition**: Networks of nodes (entities) and edges (relationships).

**Examples**: Social networks, knowledge graphs, recommendation networks, citation networks

**ML Use Cases**: Social network analysis, fraud detection, link prediction, community detection

**Techniques**: Graph Neural Networks (GNN), Node2Vec, GraphSAGE

**Tools**: Neo4j, NetworkX, PyTorch Geometric

---

## 7. Multimodal Data

**Definition**: Combines multiple data types (text + image + audio + video).

**Examples**: Videos with captions, medical records (images + text), e-commerce (images + descriptions), social media posts

**ML Use Cases**: Video captioning, visual question answering, multimodal sentiment analysis

**Models**: CLIP, DALL-E, Vision Transformers
