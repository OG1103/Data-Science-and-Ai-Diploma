**Data Analysis** is about examining existing data to answer specific questions and provide insights for business decisions. It's more focused on:
- Interpreting historical data
- Creating reports and dashboards
- Using tools like Excel, SQL, Tableau
- Answering "what happened?" and "why did it happen?"
- Shorter-term, practical insights

**Data Science** is broader and more technical, involving building predictive models and systems. It includes:
- Machine learning and AI
- Programming (Python, R)
- Statistical modeling and algorithms
- Predicting future outcomes
- Answering "what will happen?" and "what should we do?"
- Building automated data products

**Simple analogy:**
- **Data Analyst**: Looks at last year's sales data to understand which products sold best
- **Data Scientist**: Builds a model to predict which products will sell best next quarter

**Overlap**: Data scientists often do data analysis, but data analysts typically don't build ML models. Data science requires more programming and statistical knowledge, while data analysis focuses more on business intelligence and visualization.

Think of data analysis as a subset of data science - data science encompasses analysis but goes further into predictive modeling and automation.
