# Machine Learning vs Deep Learning

## Machine Learning (ML)

**What it is:** Algorithms that learn patterns from data to make predictions without being explicitly programmed

**How it works:**

- You feed it data with examples
- It finds patterns and rules
- It uses those patterns to make predictions on new data

**Types:**

- Supervised learning (labeled data): spam detection, price prediction
- Unsupervised learning (unlabeled data): customer segmentation, anomaly detection
- Reinforcement learning: game playing, robotics

**Example:** Teaching a computer to recognize spam emails by showing it thousands of examples of spam vs. not spam

---

## Deep Learning (DL)

**What it is:** A subset of ML that uses neural networks with many layers (inspired by the human brain)

**How it works:**

- Uses artificial neural networks with multiple layers
- Each layer learns increasingly complex features
- Automatically extracts features from raw data (less manual work)

**Best for:**

- Image recognition (faces, objects)
- Natural language processing (ChatGPT, translation)
- Speech recognition
- Complex pattern recognition

**Example:** Teaching a computer to recognize cats in photos - it learns edges → shapes → features → "cat" automatically through layers

---

## Key Difference: Feature Extraction

### Traditional Machine Learning

**Manual Feature Extraction** - YOU tell the algorithm what to look for

**Process:**

1. You manually identify important features
2. You extract/engineer these features from raw data
3. Feed processed features to ML algorithm
4. Algorithm learns from these features

**Example (Email Spam):**

- You decide: "Check for words like 'free', 'winner', count exclamation marks"
- You write code to extract these features
- ML algorithm uses your features to classify spam

**Challenge:** Requires domain expertise and manual work however doesn't need as much data nor computational power/time as deep learning as i have already given it the set of features that it should learn from.

---

### Deep Learning

**Automatic Feature Extraction** - The network figures out what to look for

**Process:**

1. Feed raw data directly (images, text, audio)
2. Neural network automatically discovers important features
3. Each layer learns progressively complex features
4. No manual feature engineering needed

**Example (Image Recognition):**

- Layer 1: Learns edges and basic shapes (automatic)
- Layer 2: Learns simple patterns (automatic)
- Layer 3: Learns complex objects (automatic)
- Layer 4: Learns "this is a cat" (automatic)

**Advantage:** No need to manually figure out what features matter
**DisAdvantage:** Needs alot more data and computational power/time to extract those features by itself and learn from it
---

## Summary Comparison

| Aspect                 | Machine Learning                          | Deep Learning                            |
| ---------------------- | ----------------------------------------- | ---------------------------------------- |
| **Algorithms**         | Simpler (decision trees, regression)      | Complex neural networks with many layers |
| **Feature Extraction** | Manual (you engineer features)            | Automatic (network learns features)      |
| **Data Type**          | Structured data (spreadsheets, databases) | Unstructured data (images, audio, text)  |
| **Data Requirements**  | Works with smaller datasets               | Needs massive amounts of data            |
| **Computing Power**    | Less intensive (CPU is fine)              | Very intensive (requires GPUs)           |
| **Domain Knowledge**   | Requires expertise to engineer features   | Learns features automatically            |

---

## Simple Hierarchy:

```
Machine Learning (the broader field)
└── Deep Learning (a powerful subset using neural networks)
```

**Bottom line:** All deep learning is machine learning, but not all machine learning is deep learning. Deep learning is ML on steroids - more powerful but needs more data and resources. The main advantage of deep learning is **automatic feature extraction**, while traditional ML requires you to manually tell it what features to look for.
