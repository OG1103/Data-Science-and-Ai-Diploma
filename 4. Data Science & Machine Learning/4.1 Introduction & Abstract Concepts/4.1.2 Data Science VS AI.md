# Data Roles: Quick Comparison

## Data Analysis
**What it does:** Examines past data to understand what happened
- Tools: Excel, SQL, Tableau, Power BI
- Focus: Reports, dashboards, business insights
- Questions: "What happened?" "Why did it happen?"
- Example: Analyzing last year's sales trends

## Data Science
**What it does:** Uses data to predict the future and build systems
- Tools: Python, R, statistics, machine learning
- Focus: Predictive models, algorithms, automation
- Questions: "What will happen?" "What should we do?"
- Example: Building a model to forecast next quarter's sales

**Data Science**: The broad field that includes everything
- Includes data analysis
- Includes machine learning
- Includes AI techniques
- Basically: analysis + ML/AI + engineering

## Machine Learning / AI
**What it does:** Creates intelligent systems that learn and adapt
- Tools: Neural networks, deep learning frameworks
- Focus: Automation, pattern recognition, decision-making
- Questions: "Can a machine do this?" "Can it learn on its own?"
- Example: Chatbot that improves over time, self-driving cars

**Machine Learning/AI**: Specific techniques WITHIN data science
- ML is a tool/method that data scientists use
- AI is the goal of making intelligent systems
- Both are part of the data science toolkit

---

**Simple Hierarchy:**
```
Data Science (the entire field)
    ├── Data Analysis (understanding)
    └── Machine Learning/AI (prediction & automation) - The techniques/tools that enable the learning and automate the prediction process
                                                      - The "how" behind data science prediction
```

**Important Note:** ML/AI *uses* data science methods to train and build intelligent systems. Data science provides the foundation and techniques that power AI. Data analysis is about understanding the data itself.

**Bottom line:** Analysis understands, Data Science predicts, AI automates intelligence.
