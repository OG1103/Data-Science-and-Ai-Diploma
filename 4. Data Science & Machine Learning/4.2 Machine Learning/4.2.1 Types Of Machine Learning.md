## Types of Machine Learning

### 1. Supervised Learning

**Definition**: Learning from labeled data (input-output pairs)

#### A. Classification

**Goal**: Predict categorical labels (discrete classes)

**Algorithms**:

- Logistic Regression
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Gradient Boosting (XGBoost, LightGBM, CatBoost)
- Neural Networks

**Examples**:

- Email spam detection (spam/not spam)
- Disease diagnosis (positive/negative)
- Image recognition (cat/dog/bird)
- Customer churn prediction (will leave/stay)
- Sentiment analysis (positive/negative/neutral)

#### B. Regression

**Goal**: Predict continuous numerical values

**Algorithms**:

- Linear Regression
- Polynomial Regression
- Ridge Regression
- Lasso Regression
- Decision Trees
- Random Forest
- Gradient Boosting
- Neural Networks

**Examples**:

- House price prediction
- Stock price forecasting
- Temperature prediction
- Sales forecasting
- Age estimation

---

### 2. Unsupervised Learning

**Definition**: Learning from unlabeled data (find hidden patterns)

#### A. Clustering

**Goal**: Group similar data points together

**Algorithms**:

- K-Means
- Hierarchical Clustering
- DBSCAN
- Gaussian Mixture Models (GMM)
- Mean Shift

**Examples**:

- Customer segmentation
- Document categorization
- Image compression
- Anomaly detection
- Gene sequence analysis

#### B. Dimensionality Reduction

**Goal**: Reduce number of features while preserving information

**Algorithms**:

- Principal Component Analysis (PCA)
- t-SNE
- UMAP
- Autoencoders

**Examples**:

- Data visualization
- Feature extraction
- Noise reduction
- Compression

#### C. Association Rule Learning

**Goal**: Discover relationships between variables

**Algorithms**:

- Apriori
- FP-Growth

**Examples**:

- Market basket analysis (items bought together)
- Recommendation systems
- Web usage mining

---

### 3. Semi-Supervised Learning

**Definition**: Learning from mix of labeled and unlabeled data

**Use Cases**:

- When labeling is expensive or time-consuming
- Medical image analysis
- Text classification with limited labels
- Speech recognition

---

### 4. Reinforcement Learning

**Definition**: Learning through interaction with environment (trial and error)

**Components**:

- **Agent**: Learner/decision maker
- **Environment**: World agent interacts with
- **Actions**: Choices agent can make
- **Rewards**: Feedback from environment
- **Policy**: Strategy agent follows

**Algorithms**:

- Q-Learning
- Deep Q-Networks (DQN)
- Policy Gradients
- Actor-Critic
- Proximal Policy Optimization (PPO)

**Examples**:

- Game playing (Chess, Go, video games)
- Robotics (walking, grasping objects)
- Autonomous vehicles
- Resource management
- Trading strategies

---

### 5. Deep Learning

**Definition**: Neural networks with multiple layers for complex patterns

**Types**:

#### Artificial Neural Networks (ANN)

- Fully connected layers
- General-purpose learning

#### Convolutional Neural Networks (CNN)

- Specialized for image data
- Object detection, image classification

#### Recurrent Neural Networks (RNN)

- Specialized for sequential data
- Time series, text, speech

#### Long Short-Term Memory (LSTM)

- Improved RNN for long sequences
- Language modeling, translation

#### Transformers

- Attention-based architecture
- State-of-the-art for NLP
- Models: BERT, GPT, T5

#### Generative Adversarial Networks (GAN)

- Generate new data (images, text, audio)
- Image synthesis, style transfer

---

## Evaluation Metrics

### Classification Metrics

- **Accuracy**: Percentage of correct predictions
- **Precision**: Correct positive predictions / Total positive predictions
- **Recall**: Correct positive predictions / Actual positives
- **F1-Score**: Balance between precision and recall
- **ROC-AUC**: Overall model performance measure

### Regression Metrics

- **Mean Absolute Error (MAE)**: Average absolute difference
- **Mean Squared Error (MSE)**: Average squared difference
- **Root Mean Squared Error (RMSE)**: Square root of MSE
- **R² Score**: Proportion of variance explained
- **RSS (Residual Sum of Squares)**: Total squared difference between actual and predicted values
- **ESS (Explained Sum of Squares)**: Total squared difference between predicted values and mean

### Clustering Metrics

- **Silhouette Score**: How well-separated clusters are
- **Davies-Bouldin Index**: Cluster separation measure
- **Inertia**: Within-cluster sum of squares

## Algorithm Selection Guide

| Problem Type          | When to Use            | Common Algorithms                                            |
| --------------------- | ---------------------- | ------------------------------------------------------------ |
| **Classification**    | Predict categories     | Logistic Regression, Random Forest, XGBoost, Neural Networks |
| **Regression**        | Predict numbers        | Linear Regression, Random Forest, XGBoost, Neural Networks   |
| **Clustering**        | Group similar items    | K-Means, DBSCAN, Hierarchical                                |
| **Time Series**       | Sequential predictions | ARIMA, LSTM, Prophet                                         |
| **Image Recognition** | Analyze images         | CNN, ResNet, YOLO                                            |
| **Text Analysis**     | Process language       | BERT, GPT, RNN                                               |
| **Recommendation**    | Suggest items          | Collaborative Filtering, Matrix Factorization                |
